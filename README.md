# GenGLem
molecule structure generation model

The dataset and code for the paper 'GenGLem: a generative framework for capturing chemical cliffs in energetic materials'

# Environment
Python 3.11 
Key packages: see `requirements.txt`

# Quick start
```bash
python -m venv .venv
source .venv\Scripts\activate 
pip install -r requirements.txt
python GenGLem_main.py
python GenGLem_conditions.py
